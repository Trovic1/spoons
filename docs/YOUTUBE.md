## Description
```
Your to-do app thinks every day is the same. If you live with a chronic illness, it isn't.

Spoons is a day planner for students whose energy changes from one day to the next. Set how many "spoons" you have today, and Spoons fits your tasks into that budget, keeps a reserve so you don't crash, and gives everything that doesn't fit a next step: tomorrow, part one, a ready-to-send help message, or a request for more time.

Built for the Taskforge student hackathon on Devpost.

Features

• Must-dos first, rest breaks after heavy tasks
• Help and extension messages, ready to copy
• Low Power mode for 3-spoon days
• Re-plans instantly from what tasks really cost
• Keyboard, screen reader, read-aloud, high contrast, reading font, dark mode
```
